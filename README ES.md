# 🎓 DAMFLIX

**Tu biblioteca digital para DAM.**

DAMFLIX es una plataforma creada para organizar y compartir apuntes, ejercicios, documentos y otros recursos de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

La idea es tener todo el material del curso organizado en un único lugar y poder colaborar con otros compañeros.

---

## 🚀 ¿Qué puedo hacer en DAMFLIX?

### 📚 Organizar apuntes

Los archivos están organizados mediante:

**Módulo → Tema → Archivo**

Por ejemplo:

```text
Programación
├── Tema 1
│   ├── Apuntes.pdf
│   └── Ejercicios.zip
├── Tema 2
│   └── Apuntes.pdf
└── Tema 3
    └── Practica.java
```

Puedes crear tantos temas como necesites.

---

## 📤 Subir archivos

Puedes subir prácticamente cualquier tipo de archivo.

Por ejemplo:

* PDF
* Word
* Excel
* PowerPoint
* ZIP
* Imágenes
* Vídeos
* Archivos de código
* Otros documentos

### Drag & Drop

La forma más rápida:

1. Entra en el tema donde quieres guardar el archivo.
2. Arrastra el archivo desde tu ordenador.
3. Suéltalo en la zona de subida.
4. DAMFLIX comenzará a subirlo automáticamente.

También puedes utilizar **Seleccionar archivos**.

---

## 👀 Ver archivos

DAMFLIX permite visualizar determinados archivos directamente desde la web.

Los PDF disponen de un visor integrado con opciones como:

* Cambiar de página.
* Zoom.
* Pantalla completa.
* Descargar.

Otros formatos compatibles pueden tener su propia previsualización.

---

## 🔎 Buscar archivos

Utiliza el buscador para encontrar rápidamente documentos por:

* Nombre.
* Módulo.
* Tema.
* Tipo de archivo.

También puedes utilizar filtros para encontrar exactamente lo que buscas.

---

## ⭐ Favoritos

Puedes marcar archivos como favoritos utilizando la estrella.

Después podrás encontrarlos rápidamente desde:

**Favoritos**

Los favoritos son personales.

---

## 🔒 Privacidad

Cada usuario tiene su propio espacio privado.

Por defecto:

**Nadie puede ver tus archivos.**

Tus archivos, temas y módulos pertenecen a tu cuenta.

El sistema utiliza la autenticación y los permisos de Supabase para proteger los archivos.

---

## 👥 Compartir y colaborar

También puedes compartir contenido con otros compañeros.

Puedes compartir:

* Un módulo.
* Un tema.
* Un archivo.

Dependiendo del permiso que otorgues, el usuario podrá:

### 👁️ Lector

Puede:

* Ver.
* Descargar.

### ✏️ Editor

Puede:

* Ver.
* Descargar.
* Subir archivos.
* Modificar contenido.

El propietario puede quitar el acceso cuando quiera.

---

## 📁 Compartido conmigo

En:

**Compartido conmigo**

puedes encontrar todo el contenido que otros compañeros hayan compartido contigo.

El contenido privado de otros usuarios no aparece aquí.

---

## 🕘 Archivos recientes

DAMFLIX también permite acceder rápidamente a los archivos utilizados recientemente.

---

## 💡 Recomendación

Para mantener DAMFLIX organizado:

* Utiliza nombres claros para los archivos.
* Guarda cada archivo dentro de su módulo y tema correspondiente.
* Evita subir varias copias del mismo archivo.
* Utiliza favoritos para los documentos importantes.
* Comparte únicamente el contenido que quieras que otros compañeros puedan utilizar.

---

## 🎯 Objetivo

DAMFLIX busca que todos podamos tener nuestros recursos de DAM:

**organizados → accesibles → privados → compartidos cuando sea necesario.**

**¡Disfruta de DAMFLIX! 🚀**
