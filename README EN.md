# 🎓 DAMFLIX

**Your digital library for DAM.**

DAMFLIX is a platform created to organize and share notes, exercises, documents and other resources for **Multiplatform Application Development (DAM)**.

The goal is to keep all course material organized in one place and make collaboration between classmates easier.

---

## 🚀 What can I do with DAMFLIX?

### 📚 Organize your notes

Files are organized using:

**Module → Topic → File**

For example:

```text
Programming
├── Topic 1
│   ├── Notes.pdf
│   └── Exercises.zip
├── Topic 2
│   └── Notes.pdf
└── Topic 3
    └── Practice.java
```

You can create as many topics as you need.

---

## 📤 Upload files

You can upload almost any type of file.

For example:

* PDF
* Word
* Excel
* PowerPoint
* ZIP
* Images
* Videos
* Code files
* Other documents

### Drag & Drop

The easiest way to upload a file:

1. Open the topic where you want to save it.
2. Drag the file from your computer.
3. Drop it into the upload area.
4. DAMFLIX will upload it automatically.

You can also use **Select files**.

---

## 👀 View files

DAMFLIX allows you to preview supported files directly from the website.

PDF files have an integrated viewer with options such as:

* Change page.
* Zoom.
* Full screen.
* Download.

Other supported formats may have their own preview.

---

## 🔎 Search files

Use the search bar to quickly find files by:

* Name.
* Module.
* Topic.
* File type.

You can also use filters to find exactly what you need.

---

## ⭐ Favorites

You can mark files as favorites using the star button.

You can then find them quickly in:

**Favorites**

Favorites are personal to each user.

---

## 🔒 Privacy

Every user has their own private space.

By default:

**Nobody can see your files.**

Your files, topics and modules belong to your account.

Supabase authentication and permissions are used to protect your content.

---

## 👥 Sharing and collaboration

You can also share content with other classmates.

You can share:

* A module.
* A topic.
* A file.

Depending on the permission you give, the user can have different access levels.

### 👁️ Viewer

Can:

* View.
* Download.

### ✏️ Editor

Can:

* View.
* Download.
* Upload files.
* Modify content.

The owner can remove access at any time.

---

## 📁 Shared with me

In:

**Shared with me**

you can find all the content that other classmates have shared with you.

Private content belonging to other users will not appear here.

---

## 🕘 Recent files

DAMFLIX also provides quick access to files you have recently used.

---

## 💡 Recommendation

To keep DAMFLIX organized:

* Use clear file names.
* Save each file inside the correct module and topic.
* Avoid uploading duplicate files.
* Use favorites for important documents.
* Only share content that you want other classmates to access.

---

## 🎯 Goal

DAMFLIX aims to keep all our DAM resources:

**organized → accessible → private → shared when necessary.**

**Enjoy DAMFLIX! 🚀**
